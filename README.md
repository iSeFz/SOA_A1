# Service-Oriented Architecture Assignment #1

## Description
Java application to store university students data to an XML file.

## Application Features
The program should allow users to perform the following actions:
* Add new students to the database.
* Search for a student by GPA or FirstName.
* Delete certain student by ID.

## XML File Template
> University.xml file should look something like this
```xml
<?xml version="1.0" encoding="UTF-8"?>
<University>
    <Student ID="20200134">
        <FirstName>Ahmed</FirstName>
        <LastName>Mohamed</LastName>
        <Gender>Male</Gender>
        <GPA>3.17</GPA>
        <Level>4</Level>
        <Address>Giza</Address>
    </Student>
</University>
```
